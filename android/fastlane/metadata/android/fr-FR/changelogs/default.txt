2.2.2 — Un navigateur lié affiche désormais tout.
• Un navigateur lié lit désormais tous vos cercles et messages. Le réglage « Navigateurs web » par cercle disparaît ; retirez un navigateur dans Réglages → Appareils.
• Un appareil tout juste lié affiche aussitôt les publications récentes des autres.
• Corrigé : scanner le code d'un appareil pouvait échouer pendant plusieurs minutes.
• Vidéos bien plus légères ; le HDR est converti.
